# Club Management System (DBMS Project)

A relational database management system built using XAMPP to manage university clubs efficiently.

## Features
- Student and club management
- Club membership history with support for club switching
- Event management and attendance tracking
- Leadership role management (Convenor, Co-Convenor, etc.)
- Data integrity using primary keys, foreign keys, CHECK constraints, and cascading actions
- Analytical SQL Views for:
  - Club switchers
  - Membership timelines
  - Most active clubs
  - Budget efficiency
  - Club leadership information

## Database Concepts Used
- ER Modeling
- Normalization
- Primary & Foreign Keys
- Constraints
- Views
- Aggregate Functions
- Joins
- Data Validation
- DDL, DML, and DQL

This project was developed as part of a Database Management Systems (DBMS) course to demonstrate practical relational database design and SQL implementation for a real-world club management scenario.
